# Лабораторная работа № 4 — страница отдельной записи

**Вариант 24:** анализ динамики показателей финансовой отчётности предприятий холдинга.

Проект переносит приложение `articles` из лабораторной № 3 и добавляет страницу конкретной статьи по её числовому идентификатору. Названия и содержание демонстрационных статей посвящены финансовому анализу; все учебные данные вымышлены.

## Запуск в Windows PowerShell

Выполняйте команды из корневой папки `lab4`, где находятся `requirements.txt` и `README.md`:

```powershell
python -m pip install -r requirements.txt
cd blog
python manage.py migrate
python manage.py check
python manage.py test articles
python manage.py createsuperuser
python manage.py runserver
```

Если суперпользователь уже создан, повторно выполнять `createsuperuser` не нужно.

## Адреса страниц

- `http://127.0.0.1:8000/` — архив статей аналитиков.
- `http://127.0.0.1:8000/article/1/` — детальная страница статьи с ID 1 (замените `1` на существующий ID).
- `http://127.0.0.1:8000/finance/` — сводная страница финансовых показателей и курсов валют.
- `http://127.0.0.1:8000/admin/` — административная панель Django.

Если статья с указанным ID отсутствует, представление возвращает HTTP 404. Адрес распознаётся регулярным выражением `^article/(?P<article_id>\d+)/$`, поэтому после `article/` разрешены только цифры.

## Как проверить задание

1. В административной панели создайте несколько аналитических статей о выручке, прибыли, коэффициентах важности показателей или валютных курсах.
2. Откройте архив `/`: заголовки каждой статьи должны быть ссылками.
3. Нажмите заголовок либо откройте `/article/<ID>/` с существующим числовым ID. Отобразятся заголовок, автор, дата и полный текст статьи.
4. Нажмите ссылку «Все записи», чтобы вернуться к архиву.
5. Проверьте `/article/999999/` (при условии, что такого ID нет): должна вернуться страница 404.
6. На `/finance/` доступны финансовые модели варианта 24: предприятия, отчётные периоды, показатели, значения показателей и курсы валют.

## Работа с моделью

Модель `Article` содержит `title`, `author`, `text` и `created_date`; дата создания задаётся автоматически. Метод `get_excerpt()` возвращает первые 140 символов текста и `...`, если текст длиннее 140 символов. Метод `__str__` используется вместо устаревшего `__unicode__` для совместимости с Python 3.

## Безопасность

Файл локальной базы `blog/db_project_name`, резервные копии, `.env`, виртуальные окружения и кэш Python исключены через `.gitignore`. База данных намеренно не включена в архив; `python manage.py migrate` создаст таблицы на компьютере пользователя. Не публикуйте реальные финансовые данные, пароли или токены.
