## 1. Цель работы

Изучить создание страницы отдельной записи Django по уникальному идентификатору, настройку маршрута с именованной группой регулярного выражения, передачу записи в шаблон и оформление архива и страницы записи с помощью CSS.

## 2. Ход работы

1. Создан Django-проект `blog` и подключено приложение `articles`, перенесённое из предыдущей лабораторной работы.
2. Сохранена модель `Article` с полями заголовка, автора, текста и даты создания. Метод `get_excerpt()` возвращает краткий фрагмент текста.
3. Настроен маршрут `article/<ID>/`, реализованный регулярным выражением `^article/(?P<article_id>\d+)/$`.
4. Создано представление `get_article`, которое находит статью по ID и возвращает HTTP 404, если запись не существует.
5. В шаблоне `archive.html` заголовки статей оформлены как ссылки на соответствующие страницы.
6. Создан шаблон `article.html` с заголовком статьи, автором, датой, полным текстом и ссылкой «Все записи».
7. Создан файл `articles/static/css/article.css`, подключённый к шаблонам архива и отдельной статьи. Стиль адаптирован к финансовой тематике варианта 24.
8. Сохранена финансовая сводка из предыдущей работы для отображения предприятий, отчётных периодов, показателей и курсов валют.

## 3. Проверка

После запуска проекта проверяются следующие URL:

- `http://127.0.0.1:8000/` — архив статей;
- `http://127.0.0.1:8000/article/1/` — страница записи с ID 1 (при наличии записи с таким ID);
- `http://127.0.0.1:8000/finance/` — финансовая сводка;
- `http://127.0.0.1:8000/admin/` — административная панель.

Проверяется переход по заголовку статьи, ссылка возврата «Все записи» и ответ 404 для отсутствующего ID.
